# 新增功能：首页多主题（7 套）+ 后台「主题设置」

- 完成时间：2026-11-08 03:32–03:50（+08:00）
- 一句话：把首页做成 7 套完全不套版式的模板，后台「更多设置」下面新增「主题设置」，点一下即时切换
- 当前启用：**极简白**（后可随时在后台切换）

---

## 一、后台在哪里选

菜单位置：**网站设置 → 更多设置 → 主题设置**（只有管理员 power=0 能看到、能进）
页面地址：/admin/themeset.html

- 每套主题一张卡片：缩略图按该主题的真实配色 + 版式示意绘制（终端是黑底绿条、杂志是双栏纸色、便当是网格、霓虹是发光描边……），下面写风格说明
- 「**预览**」：新窗口打开 /?theme=键名 —— 只有管理员登录状态才会按这个参数渲染，普通访客带这个参数无效，不会影响线上
- 「**启用**」：一键切换，写入配置后立即生效（前台刷新即可看到），使用中的那套会打上「使用中」标记

## 三、实现方式（很小的一处后端 + 一个页面）

| 文件 | 改动 |
|---|---|
| app/common.php | 新增 home_themes()（主题清单：名称/说明/三个配色/缩略图样式）和 home_theme_key()（读取后台选择，非法值回退默认） |
| app/controller/Index.php | index() 按当前主题渲染 view/index/themes/键名.html；管理员可用 ?theme= 预览；**主题文件缺失时自动回退经典主题，不会 500** |
| app/controller/Admin.php | 新增 themeset()（管理员校验后输出主题卡片列表） |
| app/controller/AdminAjax.php | 侧边菜单在「更多设置」下面加「主题设置」 |
| view/index/themes/*.html | 6 个新主题文件（classic 复用原来的 view/index/index.html） |
| view/admin/themeset.html | 后台主题选择页（卡片 + 预览 + 一键启用） |

保存沿用统一的 /AdminAjax/config（参数绑定 + 键名白名单 + 仅管理员可调用），配置存在 gui_configs 的 home_theme，每次请求由 Common 读入，**改完即刻生效、不用重启**。

   逐套切为启用后对比    → 访客首页与管理员预览**字节完全一致**（6/6 ✓，classic 同样可切）
   访客带 ?theme=neon    → 被忽略，仍显示已启用的主题（前端不能自行切主题）✓
   主题文件缺失          → 自动回退经典主题，实测 HTTP 200 ✓

   回归                  → 60 个 PHP 文件语法全通过；首页/注册/登录/后台各页面与接口全部正常 ✓

## 五、以后想再加一套主题（3 步）

1. 把 HTML 放到 view/index/themes/新键名.html，保留这几处模板标记：
   {:config('web.webname')}、{:config('web.title')}、{:config('web.description')}、{:config('web.keywords')}，
   以及 {$data.users} / {$data.players} / {$data.sheets} / {$data.songs}、{volist name="users" id="u"}{$u.username}{/volist}
2. 在 app/common.php 的 home_themes() 里加一行（名称、说明、三个配色、缩略图样式）
3. 后台「主题设置」立刻就能看到并切换，不用改控制器

注意：模板里不要出现 ${ 这种 JS 模板字符串、也不要出现双大括号，会和 ThinkPHP 模板语法冲突。

## 六、几个说明

- 用户墙会展示用户名（随机 12 个），不想展示可以去掉；
- 经典原版主题内部引用的是外网 CDN 的 Bootstrap/layui/font-awesome（作者原本的写法），另外 6 套都是零外链，更稳更快；
- 主题只影响首页，后台和播放器都不受影响。
- 后台顶栏「主题」图标弹出的配色面板里，标题栏加了「首页主题设置」按钮，一键直达本页（原来那个图标点出来是版本信息，已一并修好）。
