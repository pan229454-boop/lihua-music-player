# 首页主题升级 + 登录页跟着主题换配色

## 这次改了什么

之前那 6 套首页主题是「一屏一个卖点」的落地页，内容偏少、看着单薄；
这次把它们全部重做成**内容完整的整站首页**，并且让**登录 / 注册 / 找回密码页跟着首页主题换配色**。

## 一、首页主题（6 套全部重做，经典原版保留）

每套主题现在都有这些区块，不再是光秃秃的一屏：

1. 顶部导航：站点名 + 菜单 + 登录 / 注册 / 控制台按钮（已登录显示「控制台」），手机上收成汉堡菜单
2. 英雄区：徽标、大标题、副标题、两个按钮、四个会滚动增长的数字（主题套数 / 音乐接口 / 注册用户 / 收录歌曲）
3. 悬浮播放器区：后台创建过播放器就直接显示真实播放器；没有就显示播放器预览效果
4. 六宫格功能：多平台解析、歌单管理、播放器短代码、一键换风格、首页留言板、统计与服务器状态
5. 主题墙：把 7 套首页主题连同「使用中」标记一起列出来
6. 三步开始使用、常见问题（可展开）、底部行动条
7. 四栏页脚 + 返回顶部按钮

再加一些细节：顶部滚动进度条、滚动到视口才出现的入场动画、数字滚动增长、返回顶部、
移动端适配、页脚显示当前风格名，以及 theme-color 让手机浏览器状态栏也跟着变色。

每套主题的个性仍然保留，靠各自的样式实现：

| 主题 | 这次的个性 |
|---|---|
| 极简白 | 瑞士网格：大留白、1px 细线、小节带 01/02 编号、无圆角无阴影、左对齐 |
| 复古杂志 | 纸张底色 + 双线报头、衬线大字、首字下沉、无圆角、统计改成竖排 |
| 暗黑霓虹 | 纯黑底 + 网格线 + 青紫光晕、标题发光、按钮渐变、卡片描边发光 |
| 赛博终端 | 等宽字体 + 扫描线、卡片虚线边框和窗口小圆点、$ 提示符、光标闪烁 |
| 玻璃拟态 | 彩色渐变背景 + 磨砂玻璃卡片（blur）、圆角、柔和阴影 |
| 便当网格 | 六列便当拼贴、大小格子错落、暖色渐变、圆角卡片 |

技术实现：6 套主题由一个生成器统一产出（同一套语义化骨架 + 各主题自己的配色与个性样式），
以后要加区块只改一处；生成出来的文件仍然是自包含的（CSS / JS 都写在页面里，不依赖任何 CDN），
手机、内网都能正常打开。

## 二、登录 / 注册页跟随主题

- 每套主题在后台主题清单里多带了一组「登录页配色」（背景、卡片、按钮、字体、圆角、阴影）。
- 登录页、注册页、找回密码页渲染时会自动插入一段样式块（id 为 lh-auth-theme），
  把 layui 官方登录皮肤的颜色换成当前首页主题的配色。
- 后台「主题设置」页新增开关：**登录 / 注册 / 找回密码页 → 配色（跟随首页主题 / 不跟随）**，默认跟随。
- 关掉开关就回到 layui 原来的登录页样式，随时可切回。

各主题登录页的样子：霓虹是纯黑底 + 霓虹渐变按钮和发光标题；
终端是等宽字体 + 扫描线 + 虚线卡片；杂志是纸张底色 + 双线卡头 + 无圆角；
玻璃拟态是磨砂玻璃卡片；便当是大圆角 + 暖色渐变顶条；极简是细线方角。

## 三、数据来源

首页用到的数据都在 Index 控制器的 siteData() 里统一取，任何一张表不存在或查询失败都不会影响首页：

- 主题清单、主题数量
- 播放器（gui_player 最新一条，有就显示真实播放器）
- 公开歌单（gui_song_sheet 里 status=1，最多 6 条，有内容时才渲染歌单区）
- 登录状态（决定导航按钮显示登录注册还是控制台）
- 注册用户数 / 收录歌曲数（gui_users / gui_song）
