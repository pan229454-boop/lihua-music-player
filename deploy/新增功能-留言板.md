# 新增功能：首页留言板（聊天）

## 起因

数据库里一直有 gui_chat 表（uid / qq / nickname / content / time / sendtime / sendip），
app/model/Chat.php 里也有一个 loadNewList()，但原始压缩包里没有对应的控制器、路由和页面 ——
这个功能只写了一半，所以界面上完全看不到。这次把它补全成「首页留言板」。

## 做了什么

### 1. 前台接口 app/controller/ChatAjax.php（新增）

- GET  /ChatAjax/lists?id=0&limit=30
  取留言；带上 id 就只返回比它新的（轮询用）。
  返回 {code:0, data:[{id,nickname,content,time,time_tran,is_admin}], total, enable, login}
- POST /ChatAjax/send
  发留言（nickname / qq / content），返回 {code:0|-1, msg, data}。
- 校验：内容 1~200 字、昵称 1~20 字、QQ 选填且必须 4~15 位数字；strip_tags 去掉标签。
- 登录用户：昵称和 QQ 一律取账号里的（防止冒名），并标记 is_admin=1，前台显示「站长」。
- 限速：同一 IP 60 秒只能发 1 条、1 小时最多 20 条；10 分钟内不重复同一句话；
  全站 10 秒内最多 5 条（防止伪造 X-Forwarded-For 绕开单 IP 限速）。

### 2. 前台组件 public/res/chat/chat.js 与 chat.css（新增）

- 右下角悬浮「留言板」按钮，点开从右侧滑出面板；有未读留言时按钮上带红点。
- 面板打开后每 8 秒增量拉取新留言；发送成功立刻追加，不用刷新页面。
- 纯原生 JS，不依赖 jQuery / layui（6 套新首页主题本来就没有 jQuery）；
  所有文字都用 textContent 输出，留言里的 HTML 不会被当代码执行，天然防 XSS。
- 游客第一次填的昵称 / QQ 存在 localStorage，下次自动带出。
- 支持用 /?chat=1 或 #chat 直接展开面板，方便把留言板链接直接发给别人。

### 3. 首页统一注入 app/controller/Index.php

- 新增 withChatWidget()：在所有首页主题（经典 + 6 套新主题）的 </body> 前统一插入
  chat.css 与 chat.js，主题文件一行都不用改。
- 后台把留言板关掉后，首页不再注入，接口也会拒绝留言。

### 4. 后台「留言管理」

- 菜单：服务器状态 → 留言管理（跳转 /chat/act/list）。
- 页面 view/admin/chat/list.html：留言板开关 + 留言列表（ID / 昵称 / QQ / 内容 / IP / 时间），
  支持按昵称或内容搜索、单条删除、勾选批量删除。
- 接口 AdminAjax::chat()：act=list 列表（layui 表格格式，带分页）、act=del 删除（支持 id 或 ids）。
- 这两个接口和页面都只对管理员（power=0）开放，其它人返回「没有权限」。

### 5. 数据库

- 沿用原来的 gui_chat 表，没有改表结构（保留原字段，兼容作者原来的代码）。
- 新增一条配置 chat_enable=1（在「留言管理」页里可以随时开关）。

## 验证记录

- 前台：游客留言成功；60 秒内第二次被限速拦下；空内容 / 超长 / 错 QQ 都有明确提示；
  换 IP 连发第 4 条起被全站突发保护拦下。
- 防冒名：带管理员 Cookie 发留言时昵称被纠正成账号名 admin、QQ 取账号里的值，标记为站长。
- 防 XSS：留言内容带 <script> 与 <img onerror> 时，入库前后标签都被剥掉。
- 开关：关闭后首页不再注入 chat.js（注入次数 0），发送接口返回「留言板已关闭」，lists 里 enable=0；
  重新开启后恢复。
- 后台：列表接口返回正常，单条删除、批量删除、非法 id、未登录访问都符合预期；
  前台留言被删后数据库归零。
- 组件流程：用最小 DOM 替身在 node 里跑通「初始化 → 打开 → 渲染 → 发送 → 关闭」21 项断言全部通过
  （node --check 语法通过）。
- 全站回归：首页（各主题）200 且都带上留言板，后台所有页面 200，全部 PHP 文件语法通过。

## 说明

- 首页右下角那个粉色圆角按钮就是留言板入口；想直接展开面板可以访问 /?chat=1。
- 留言数据存在 gui_chat 表，后台「留言管理」里能看、能删。
- 手机浏览器的无障碍服务没开，所以这次没法在真机上截图确认外观；
  打开首页看一眼即可，或开启 DSHA 无障碍服务后我再上去核一遍。
