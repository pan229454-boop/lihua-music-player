# 新增：域名授权功能开关（更多设置里控制）

## 需求

在「更多设置」里加一个域名授权功能开关：

- 开启：播放器编辑页显示「域名授权」标签（已授权域名列表 + 新增授权表单），授权功能可用；
- 关闭：功能不启用，这些界面整块不再展示，授权接口也不再受理。

另外明确了一条规则：授权顶级域名（例如 example.com）后，它的所有二级域名（a.example.com 等）默认都可用，不用逐个授权。

## 改动

1. 新增配置项 auth_domain_enable（gui_configs 表，1=开启 / 0=关闭，缺省按开启处理），
   install.sql 里也补上了默认值。判断函数放在 app/common.php 的 domain_auth_enabled()。

2. 更多设置页（view/admin/moreset.html）新增一张「域名授权」卡片，里面是开关 + 说明 + 单独的保存按钮。
   说明里写清了三件事：开启/关闭分别是什么效果、关掉以后已授权的记录会保留、顶级域名覆盖二级域名。

3. 播放器编辑页（view/admin/player.html）：
   - 标签标题和面板都包了条件，关闭时不渲染「域名授权」标签；
   - 关闭时「获取代码」自动变成默认选中的标签（不会出现一个面板都不显示的情况）；
   - 打开时和以前完全一样。

4. 接口层（app/controller/AdminAjax.php 的 Player act=auth / delauth）：
   - 开关关闭时直接返回「域名授权功能已在「更多设置」里关闭」，不能绕过界面直接调接口；
   - 顺手做了域名规范化：去掉 http(s):// 、路径、端口、结尾斜杠，统一小写（测试里 HTTP://Test.COM/x 会存成 test.com）；
   - 加了二级域名覆盖判断：父域名已授权时再授权子域名会提示不用重复授权。

5. 顺手修了一个已有的小毛病：授权接口在没传 remark 字段时会因为 Undefined array key 报错（调试模式下直接 500），
   改成 empty() 判断，现在缺字段只会按「无备注」处理。界面上一直是带 remark 提交的，所以以前没人碰到。

6. 顺手改掉「更多设置 → 登录保持」里那句过时提示（原来写「同一个账号在别处登录，先前那台会被顶下线」，
   多设备会话改完后已经不成立了）。

## 验证

开关开启：

- 播放器页有「域名授权」标签，授权域名输入框、新增授权按钮、已授权域名列表都在；
- 新增 example.com 成功；再加 a.example.com 会提示「已经授权过 example.com，它的所有二级域名默认都可用」；
- HTTP://Test.COM/x 会规范化成 test.com 存下来；重复授权提示「域名已存在」；空域名提示「请输入要授权的域名」；
- 授权记录会出现在播放器页的已授权域名列表里；删除授权正常。

开关关闭：

- 播放器页 HTML 里不再有「域名授权」标签、授权域名输入框（adddomain 只出现在脚本里，界面上没有）；
- 「获取代码」「插件下载」两个标签正常，获取代码为默认选中；
- 直接 POST 授权/取消授权接口都会返回「域名授权功能已在「更多设置」里关闭」；
- 更多设置页的开关显示为关闭状态。

其他：63 个 PHP 文件语法全部通过；后台各页面、首页、留言板接口都是 HTTP 200；日志没有新增报错。
测试用的授权记录（example.com / test.com）已清理，播放器授权表保持为空。
