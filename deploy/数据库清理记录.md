## 六、清理过程中顺带发现并修掉的 2 个 500

1. **直接访问 /LoginAjax/login（空 POST 或 GET）返回 500**
   根因：ThinkPHP 的 Validate 对「完全空的数组」会直接判定通过，于是代码走到 Users::checkUsername($data['username']) 时取不到键 → Undefined array key → 500。
   现在返回：{"code":-1,"msg":"请输入用户名和密码"}

2. **直接访问 /LoginAjax/checkcode 返回 500**
   根因：它是内部校验方法（原来只被注册/找回密码内部调用），却是 public 且参数必填；即使补上默认值，它返回布尔值 TP 也不接受（variable type error：boolean）。
   现在改为 protected 内部方法，直接访问返回 404，注册/找回密码流程不受影响（已验证：注册提交 → 邮箱验证码错误；发验证码 → 邮箱格式校验）。

另外扫了一遍其他提交类接口的空请求：reg / find / sendcode / Webapi/getFavicon / AdminAjax/config 都返回正常的 200。
