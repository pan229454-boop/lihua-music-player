# 首页主题重做（6 套完全不同版式）+ 登录页跟着主题换配色

## 为什么又重做了一次

第一版 6 套主题是「一屏一个卖点」的落地页，内容太少、看着单薄；
第二版把它们做成了内容完整的整站首页，但 6 套用的是同一套骨架、只换了配色和字体，
看起来像同一个模板套了 6 层皮。用户反馈「都变成套模板了，模版创意不能是一样的」，
所以第三版把 6 套彻底拆开，每套一个完全不同的版式创意，不再是同一个骨架换皮。

## 一、6 套主题各自的版式创意

| 主题 | 版式创意（结构和交互都不一样） |
|---|---|
| 极简白 minimal | 瑞士网格排版：细线顶栏、巨型标题、两栏「导语 + 数据定义表」，正文全部是「编号 + 标题 + 内容」的细线行，不是卡片；风格做成一张细线表格，FAQ 是 +/− 行。整页零圆角零阴影。 |
| 复古杂志 magazine | 报纸头版：双线报头 + 期号 + 定价 + 报头导航，头条大字标题 + 署名行，正文用 CSS 三栏排版（column-count）带首字下沉和居中引语，右侧「本刊数据 / 目录（带引导点线）/ 开始使用」三个方框，功能是三条一行的专栏文章，风格做成带页码的「索引」，问答是「问 / 答」体，页脚是版权说明（colophon）。 |
| 暗黑霓虹 neon | 夜店海报：全屏英雄区 + 青色粉色双光晕 + 扫描线，右侧是竖排（writing-mode）边栏导航，标题超大且发光，下面一条无限跑马灯，章节用切角（clip-path）霓虹面板 + 描边大数字，里面有 SVG 环形动画 + 跳动的均衡器 + 主题霓虹胶囊。 |
| 赛博终端 terminal | 一个终端窗口：整页就是一个带三点和标题栏的终端，内容是一段真实风格的 shell 会话（cat /etc/motd、ls -lh /opt/features/、./play.sh --now、theme --list、man quickstart、man faq、./register.sh），功能用带权限位的列表、风格用 [key] + 当前标记输出；底部有一个可以真的输入命令的提示符（help / theme --list / whoami / free -h / ls features / man faq / clear，支持点命令按钮或回车，未知命令会回 command not found）。 |
| 玻璃拟态 glass | 悬浮面板 + 底部 Dock：没有顶部导航，页面左上角一个胶囊标签，底部是 macOS 风格悬浮 Dock（首页/播放器/功能/风格/问答/登录/注册，悬停会放大）；背景 3 个色彩光斑缓慢漂移；英雄区左边磨砂玻璃卡片、右边 4 块大小不一、带轻微旋转的玻璃格（悬停回正上浮）；功能用 column 瀑布流玻璃卡；播放器是一条悬浮播放条（封面 + 进度 + 播放键）；风格是横向滑动的玻璃胶囊。 |
| 便当网格 bento | 单屏便当仪表盘：整页是一个 4 列便当网格，所有内容都是格子——大标题格、四个数据格（橙、白、青三色）、深色正在播放格、快捷入口格、2x2 功能迷你格、风格色卡格、三步上手格、FAQ 格、CTA 格；顶部是悬浮胶囊导航。 |

共同点只有「数据来源」和主题切换机制：都从 Index 控制器的 siteData() 取真实数据，
播放器、用户数、歌曲数、当前主题名都来自后台，主题墙都带「使用中」标记，
都是自包含 CSS/JS（不依赖 CDN、不依赖 jQuery），都做了移动端适配。

## 二、登录 / 注册页跟随主题

- 每套主题在 home_themes() 里带一组「登录页配色」（背景、卡片、按钮、字体、圆角、阴影）。
- 登录页、注册页、找回密码页渲染时自动插入一段样式块（id 为 lh-auth-theme），
  把 layui 官方登录皮肤换成当前首页主题的配色。
- 后台「主题设置」页新增开关：登录 / 注册 / 找回密码页 → 配色（跟随首页主题 / 不跟随），默认跟随。
- 关掉开关就回到 layui 原来的登录页样式，随时可切回。

各主题登录页的样子：霓虹是纯黑底 + 霓虹渐变按钮和发光标题；终端是等宽字体 + 扫描线 + 虚线卡片；
杂志是纸张底色 + 双线卡头 + 无圆角；玻璃拟态是磨砂玻璃卡片；便当是大圆角 + 暖色渐变顶条；
极简是细线方角。

## 三、数据来源

首页用到的数据都在 Index 控制器的 siteData() 里统一取，任何一张表不存在或查询失败都不会影响首页：

- 主题清单、主题数量（home_themes()）
- 播放器（gui_player 最新一条，有就显示真实播放器，没有就显示预览）
- 公开歌单（gui_song_sheet 里 status=1，最多 6 条）
- 登录状态（决定导航按钮显示登录注册还是控制台）
- 注册用户数 / 收录歌曲数（gui_users / gui_song）

- 游客看到登录 / 免费注册，管理员看到控制台
- 登录、注册、找回密码页带当前主题配色，切主题会同步变化；开关关掉后样式块数量为 0
- 其它页面和接口回归正常

## 五、后台怎么用

后台「主题设置」里每套主题都有预览和启用按钮：

- 预览：新窗口打开 /?theme=键名（只有管理员登录状态下才按参数渲染，普通访客看不到）
- 启用：写入 home_theme 配置，所有访客立即看到

经典原版保留没动，想让它也升级可以直接说。
