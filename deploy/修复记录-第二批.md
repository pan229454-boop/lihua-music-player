## 二、⚠️ 必须知道的一件事：邮件功能本身是坏的

`extend/PHPMailer/SendEmail.php` 里写死了作者的 SMTP：

```php
public static $Host = 'smtp.qq.com';
private static $Username = 'cenguigui@qq.com';
private static $Password = '********';   // 授权码被抹掉了
```

**这导致"发送邮箱验证码"永远失败**（返回「发送验证码失败」），因此**注册和找回密码目前走不完流程**。这不是本次改动造成的，是从包里带出来的状态。

要让它可用，把上面三行换成你自己的邮箱 SMTP（QQ 邮箱需在设置里开启 SMTP 并使用**授权码**而非登录密码），改完即可。验证码的校验逻辑我已经修好并测过了，SMTP 一填就能用。

另外 `type=local` 的歌词地址现在要求是**公网 http/https**。如果你以后把歌词文件放在局域网/本机地址上导致取不到，告诉我，我给这一条加个可配置白名单。
