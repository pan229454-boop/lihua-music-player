# 修复：播放器「插件下载」全部不可用

## 现象

后台「播放器管理 → 编辑播放器 → 插件下载」四个按钮都点不动：

| 按钮 | 原来的地址 | 实际情况 |
|---|---|---|
| WordPress 插件 | /down/wordpress/WordPress-MyhkPlayer-20200712.zip | 404：public 下根本没有 down 目录，压缩包从没随开源包发出来 |
| Typecho 插件 | /down/typecho/Typecho-MyhkPlayer-20200712.zip | 404：同上 |
| Emlog 插件 | http://www.emlog.net/plugin/327 | 跳到 https 后 404，官方插件早已下架 |
| Z-Blog 插件 | http://app.zblogcn.com/?id=1803 | 这个外站还活着（HTTP 200），但用 http 打开、且是第三方站 |

另外「获取代码」里的代码框是前端 JS 拼出来的（要等 jQuery 从 bootcdn 加载完），
CDN 慢或被墙时一直是空的，也会让人觉得「不能用」。

## 处理

1. 做了 5 个真能下载的嵌入包，放在 public/down/ 下：

   - down/wordpress/WordPress-MyhkPlayer.zip — 真 WordPress 插件（myhk-player/myhk-player.php），
     带插件头，用 wp_footer 钩子在页面底部输出播放器；没配置时只输出一行注释，不会弄坏别人网站。
   - down/typecho/Typecho-MyhkPlayer.zip — readme + footer 片段。
   - down/emlog/Emlog-MyhkPlayer.zip — readme + footer 片段（注明官方老地址已 404）。
   - down/zblog/ZBlog-MyhkPlayer.zip — readme + footer 片段。
   - down/common/Player-Embed-Universal.zip — 通用包（readme + 代码片段 + demo.html）。
   旧文件名 WordPress-MyhkPlayer-20200712.zip / Typecho-MyhkPlayer-20200712.zip 也一并生成，老书签也能下。

2. 又做了「下载即用」的动态包：新增 Admin 的 pluginzip 动作
   （/admin/pluginzip/id/播放器ID.html?type=wordpress|typecho|emlog|zblog|common）。
   它把静态包读出来，把里面的占位地址换成 get_domain()（本站地址）、把播放器 ID 换成当前这个播放器，
   再打包用 download() 直接返回，所以下载下来的包不用改任何东西，装上就能用。
   - 只有登录的管理员能下（未登录返回「请登录后再进行操作！」）；
   - type 参数白名单过滤，非法值回落到通用包，没有路径穿越；
   - 生成物缓存在 runtime/pluginkit/ 下。

3. 「插件下载」标签页重写：开头写明当前版本免插件，播放器就是一段 HTML + JS；
   五张卡片分别对应 WordPress / Typecho / Emlog / Z-Blog / 通用包，按钮指向动态包，
   并额外给出静态通用包的链接（要给别人用、或不想带本站信息时用）。
   Emlog 那张注明官方老地址已失效；Z-Blog 那张额外保留第三方插件站外链（加了 rel=noopener）。

4. 「获取代码」的代码框改成服务端直接渲染好（不再等 JS），并加了「复制代码」按钮；
   前端 JS 那份拼接逻辑保留，两边内容一致。

5. 顺手修了 /admin/player.html、/admin/songSheet.html 缺参数时的 500：
   Admin::Player() 和 Admin::songSheet() 参数给了空值默认，缺 ID 时走「页面不存在」的友好提示页。

## 验证

- 7 个静态下载链接（含两个旧文件名）全部 HTTP 200，Content-Type: application/zip
- 5 个动态包全部 HTTP 200 且是合法 zip；解出来的 WordPress 插件里
  define('MYHK_PLAYER_API','http://127.0.0.1:8080') 和 define('MYHK_PLAYER_ID','6aef95169728b')
  已经填好，代码片段也是真实地址；插件文件 php -l 通过
- 未登录访问动态下载：返回「请登录后再进行操作！」，没有变成公开文件接口
- 非法 type（../../etc）：回落到通用包，无路径穿越
- 播放器页 HTTP 200，5 个下载按钮指向动态包，代码框在源码里就有内容，复制按钮和 JS 都在
- 域名授权卡片没有被误删（adddomain 仍在）
- 页面内联 JS 用 node --check 通过；62 个 PHP 文件语法通过；其它页面回归正常
- 播放器本身的接口 /api/PlayerJs/id/6aef95169728b 返回 200、application/javascript（124 KB），
  也就是说复制出来的代码是真能跑的
